# iOS Lockscreen Music Player

이 프로젝트는 iOS 잠금화면 스타일의 음악 플레이어 UI를 웹으로 구현한 것입니다.  
iOS 스타일의 락스크린에서 음악을 제어하는 인터페이스를 클론하여, 웹에서도 동일한 디자인과 기능을 사용할 수 있도록 만들었습니다.

## 기능

- 앨범 아트와 함께 곡 정보 표시
- 재생/일시정지, 이전/다음 트랙 기능
- 진행 바를 통한 시간 조정
- 실제 음악 파일을 사용하여 동작
- 반응형 디자인으로 다양한 화면 크기에서 사용 가능
